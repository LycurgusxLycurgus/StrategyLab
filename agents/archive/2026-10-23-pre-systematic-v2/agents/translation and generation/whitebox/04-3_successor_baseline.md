# 04.3 Successor Strategy Reseed Prompt

Phase 4.3 is the optional loop from a completed but non-production lineage back to the creation workflow. For new work, it starts a fresh Python2Pine reference-first intake by default; the finished lineage supplies constraints and evidence, not a mutation recipe. It follows `agents/docs/universal_mutation_constitution.md`.

## Python2Pine reference-first successor route

Carry forward verified constraints, rejected assumptions, source authority,
unresolved questions and comparable evaluation requirements—not tuned values,
rules or inherited verdicts. A new native idea uses `reference_v1` create; an
open-source strategy/indicator uses immutable source provenance and the
appropriate `replicate` or `translate` path; a material change creates an
explicit child/improve transition. A new indicator prerequisite is tested as an
indicator component before order rules. The successor earns its own
specification, independent cases, raw-data/execution evidence and fixed
baseline. Select Pine only when it is the target or source evidence requires it;
TradingView corroboration remains a later claim-driven target step.

## Origin/operation duties — `reference_v1`

Preserve the old lineage's origin, source bytes, operation history, rule-group
mapping, transformations, independent verdicts and unresolved claims. Decide
whether the proposal is a new procedure or an adapted descendant; do not erase
discretionary provenance merely because its reference is now systematic.

Select operation and conditional duties explicitly: create earns a new rule
contract without an artificial source gate; replicate requires source mapping
and oracle; translate requires ambiguity, selected interpretations and objective;
improve preserves the accepted parent and needs declared adaptation permission.
For a genuinely new lineage, classify its actual sources anew and retain the
link to predecessor lessons. Mixed origin preserves executable groups and
isolates discretionary decisions; it does not prescribe a statistical model.

Assign applicable A-F scenarios and rejecting controls in the successor handoff.
Transfer evidence-backed constraints, not PASS values, tuned parameters or
unproved source equivalence. A novel indicator returns to indicator-first
Phase 1/1.5 before strategy orders. Hand the next operator source/parent identity,
selected operation, rule provenance, fidelity scope, blockers and the specific
criteria to re-earn; route new work to START_REFERENCE_INTAKE.
